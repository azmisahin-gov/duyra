# DUYRA v0.1.6

## Windows uygulama kimliği

- DUYRA simgesi EXE dosyasına gömülür; Dosya Gezgini, görev çubuğu ve pencere simgesinde kullanılır.
- Windows dosya özelliklerine ürün adı, dosya açıklaması, üretici, özgün dosya adı, telif ve Türkçe kaynak dili eklenir.
- Dosya ve ürün sürümü doğrudan Cargo paket sürümünden üretilir; sürüm bilgisi iki yerde elle güncellenmez.
- Windows dosya özellikleri Release derlemesinde otomatik olarak doğrulanır.
- macOS ve Linux derlemeleri Windows kaynak aracını çalıştırmaz.
