# DUYRA v0.1.12

## Windows yazma koruması ön kontrol özeti

- Ayarlar bölümüne **Ön kontrol sonucunu kopyala** düğmesi eklendi.
- Kullanıcı düğmeye bastığında Windows ürün adı, edisyon, derleme, DUYRA yönetici yetkisi, destek kapsamı ve bilgisayar düzeyi `Deny_Write` kayıt durumu panoya kopyalanır.
- Ham kayıt defteri hata metinleri veya özel dosya yolları özete eklenmez; ek okuma uyarıları yalnızca sayı olarak gösterilir.
- Özet otomatik kaydedilmez, günlük dosyasına yazılmaz veya ağa gönderilmez.

## Güvenlik ve kapsam sınırları

- Bu özellik yalnızca mevcut Windows ön kontrol sonucunu paylaşılabilir metne dönüştürür. Sistem ayarlarını veya Grup İlkesi kayıtlarını değiştirmez.
- Yönetici yetkisi istemez ve USB aygıtını keşfetmez, açmaz veya okumaz.
- `Deny_Write` bilgisayar düzeyindeki ilke kaydıdır. Bu değer, tek başına belirli bir USB aygıtının fiilen salt okunur olduğunu kanıtlamaz.
- Linux sürümünde Windows'a özgü ön kontrol kullanılabilir değildir; mevcut platform açıklaması korunur.

## Doğrulama

- Windows biçim denetimi, Clippy, birim testleri ve Windows x64 derlemesi CI'da çalıştırılır.
- Linux görsel ve sahte verili etkileşim testi CI'da çalıştırılır.
- Windows panosuna gerçek kopyalama davranışı son kullanıcı kabulüyle doğrulanacaktır.
