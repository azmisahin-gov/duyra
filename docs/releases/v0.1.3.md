# DUYRA v0.1.3

## Grafik bağdaştırıcılarını doğru listeleme

- Windows aygıt listesindeki mevcut grafik bağdaştırıcıları ayrı ayrı gösterilir.
- Hibrit dizüstü bilgisayarlarda Intel tümleşik grafik birimi ile NVIDIA ayrık GPU aynı listede görülebilir.
- DUYRA'nın o anda ekran çizmek için kullandığı grafik birimi ayrıca belirtilir.
- Grafik biriminin listelenmesi, ses çözümleme motorunun o GPU'da çalışabildiği anlamına gelmez.

## Görünüm

- Grafik birimi göstergesi ana ekranın ortasına hizalandı.

## Güncelleme

- İmzalı otomatik güncelleme paketi korunmuştur. Önceki sürümden uygulama içi güncelleme desteklenir.
